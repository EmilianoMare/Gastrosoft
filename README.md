## Características Principales
- Gestión de menús y productos
- Control de inventario
- Sistema de ventas y facturación
- Gestión de mesas y reservas
- Reportes y estadísticas
- Múltiples idiomas (Español, Inglés, Francés, Árabe, Turco)
- Integración con sistemas de pago
- Generación de códigos QR

## Requisitos del Sistema
- PHP 7.4 o superior
- MySQL 5.7 o superior
- Apache/Nginx
- Extensiones PHP: mysqli, curl, gd, mbstring

## Instalación
1. Subir los archivos al servidor web
2. Configurar la base de datos en `application/config/database.php`
3. Ejecutar el instalador desde `/install`
4. Seguir las instrucciones del instalador
